# Project Instructions

## Package Management

**ALWAYS use `uv` as the package manager for this project.**

- For installing packages: `uv pip install <package>`
- For installing from requirements.txt: `uv pip install -r requirements.txt`
- Do NOT use `pip` or `pip3` - use `uv pip` instead

## Python Environment

- Use the virtual environment at `.venv/` in the project root
- Activate it with: `source .venv/bin/activate` (Unix/macOS) or `.venv\Scripts\activate` (Windows)
